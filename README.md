# Frostpass

Ein Maze-Tower-Defense im Stil der Warcraft-III-Karte Wintermaul. Gegner kommen durch zwei Tore oben und wollen zum Portal unten; du baust ihnen ein Labyrinth aus Türmen in den Weg.

Kampagne mit 30 Wellen und 5 Bossen, Endlos-Modus, verzweigte Turm-Upgrades, Wellen-Timer, Zinsen, Zoom und automatisches Speichern.

## Auf dem iPhone installieren

1. Die GitHub-Pages-Adresse dieses Repos in **Safari** öffnen.
2. Unten auf **Teilen** tippen, dann **Zum Home-Bildschirm**.
3. Frostpass startet danach im Vollbild und läuft auch ohne Internet.

## Dateien

- `index.html`: das ganze Spiel
- `manifest.webmanifest`: Name, Icon und Vollbild für den Home-Bildschirm
- `sw.js`: hält das Spiel offline verfügbar
- `fonts/`, `icons/`: Schriften (SIL Open Font License) und App-Icons
